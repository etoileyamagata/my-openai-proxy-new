確認して、eBayへ出品

AILISの商品情報に画像を加え、eBayの事前検査後に公開します。

Sandbox · テスト

担当者ログイン

管理者から案内されたログイン名とパスワードを入力してください。

共有フォルダのAILISから引き継いだ商品は、ログイン後に表示します。

接続設定

接続未確認

eBayの画面でログインしてAILISとの接続を許可します。接続設定と作業中の商品は全PCで共有します。

店舗ごとの商品所在地

商品に付いている在庫店舗から発送元を選びます。各店舗の都市・都道府県・国を英語で登録してください。

出品に使うビジネスポリシー

既存の「米国向け配送・返品不可・Managed Payments」に対応するポリシーを選びます。送料・発送日数はeBay側のポリシーが適用されます。

認証情報を変更した場合は、保存後に接続を再確認してください。本番出品の設定も解除されます。

作業中の商品

商品情報はAILISから引き継ぎます

商品入力画面の「eBay一括用」からGATE判定・商品属性の確認を進め、「画像・API出品へ進む」を押してください。

まずは「接続設定」でSandboxアカウントを設定できます。

  1. 1 商品内容
  2. 2 画像
  3. 3 事前検査
  4. 4 確認・出品

1 商品内容

商品説明・Item Specifics

価格・属性の修正は元のAILIS画面で行い、GATE判定後に引き継ぎ直してください。

2 商品画像

先頭の画像がメイン画像です。最大24枚まで登録できます。

JPEG・PNG・GIF、1枚12MB以下。選択するとeBayへ画像を送信します。

Sandboxでは、テストに使用できる公開HTTPS画像URLを登録してください。

3 eBayで事前検査

商品内容、画像、ポリシーをeBayに送信して確認します。この段階では出品は公開されません。

4 確認して出品

画像登録：Media API ／ 検査・出品：Trading API
接続設定・作業中の商品は共通サーバーに保存されます。
